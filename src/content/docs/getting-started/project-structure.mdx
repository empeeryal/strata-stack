## Conventions

### Colocated tests

Unit tests live next to the code they cover as `*.test.ts` or `*.test.tsx`. Tests that span
several modules go in `tests/unit`. End-to-end tests live in `tests/e2e`.

### Path alias

`@/` points at `src/`. Use it for imports inside the application so files can move without
rewriting relative paths.

```ts
import { cn } from '@/lib/utils';
```

### Where server code lives

Anything that reads secrets or talks to the database belongs in `src/lib`, `src/db`,
`src/actions`, `src/middleware.ts` or an API route under `src/pages/api`. Components and
layouts receive data as props.

### Reserved file names

Astro 7 treats `src/fetch.ts` as the advanced-routing entrypoint and `src/middleware.ts` as
middleware. Do not create a `src/fetch.ts` for unrelated code.

## Generated files

The following are produced by tooling and are ignored by Git: `dist/`, `.astro/`, `.vercel/`,
`.netlify/`, `.wrangler/`, `worker-configuration.d.ts`, `.data/` (local database),
`coverage/`, `playwright-report/` and `test-results/`.
